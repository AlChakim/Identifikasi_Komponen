ALUR PENGGUNAAN

Bagaimana Sistem Bekerja

Dari pemindaian sensor kamera hingga analisis mendalam dengan AI dalam 5 langkah sederhana.

01
📷

Nyalakan Kamera

Aktifkan webcam perangkat atau unggah file foto komponen elektronik dari komputer Anda.

02
⚡

Ekstraksi Frame

Browser mengalirkan frame gambar beresolusi 640x480 secara terkompresi ke backend AI.

03
🧠

Inferensi YOLO11s

Model neural network memprediksi lokasi bounding box, kelas, dan tingkat confidence score.

04
📊

Tampilan Hasil

Bounding box tergambar di layar secara real-time lengkap dengan nama dan kategori komponen.

05
💬

Eksplorasi AI

Buka AI Assistant untuk menanyakan pinout, skema rangkaian, dan contoh kode Arduino.
