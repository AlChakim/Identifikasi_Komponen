An AI-powered electronic component identification system using YOLO11s Computer Vision. Detects and recognizes 65 electronic component classes through real-time camera input or image uploads, with component information and an AI Assistant interface.

# ElectroVision AI

**Smart Electronics Recognition Powered by Artificial Intelligence**

ElectroVision AI is a web-based electronic component identification application that uses Computer Vision and Artificial Intelligence to detect and recognize electronic components automatically.

Powered by a custom-trained **YOLO11s object detection model**, the system supports 65 electronic component classes, helping users identify electronic devices and explore their functions more easily.

## Key Features

- **Real-Time Object Detection** — Identify electronic components through a webcam.
- **Image Upload Detection** — Upload component images for automatic identification.
- **65 Component Classes** — Recognize various electronic components, including microcontrollers, sensors, motors, displays, and electronic modules.
- **Detection Visualization** — Display bounding boxes, component names, and confidence scores.
- **Component Explorer** — Explore supported electronic components and their information.
- **AI Assistant Interface** — Provides a conversational interface designed to help users understand electronic components.

## Technologies

- Python
- YOLO11s
- Ultralytics
- Computer Vision
- HTML, CSS, JavaScript
- Artificial Intelligence

## Project Purpose

ElectroVision AI aims to make electronic component identification easier, faster, and more accessible through AI-powered visual recognition. This application is designed to support students, electronics enthusiasts, and beginners in learning about electronic components.
